# MindEase AI 🧠

### AI-Based Exam Wellness Companion

MindEase AI is a machine learning-based web application designed to help students reflect on their study habits, sleep routine, and exam stress.

## Features
- Study routine and sleep habit inputs
- Exam stress indicator using a machine learning model
- Personalized study, sleep, and relaxation tips
- Interactive Streamlit interface

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Jupyter Notebook

## Project Files
- `app.py` — Streamlit web application
- `exam_anxiety_model.ipynb` — Model training notebook
- `exam_anxiety_model.pkl` — Trained model
- `test_app.py` — Application tests
- `requirements.txt` — Python dependencies

## How to Run Locally

1. Clone this repository.
2. Install the dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `streamlit run app.py`

## Disclaimer
This is an educational prototype, not a medical diagnostic tool.
